# Layered Challenge

Read the mission and pe-git-research.

First check the statement and assumptions, then the argument, then independent examples or experiments, then its claimed significance. These are lenses, not a compulsory sequence. A different representation or an approved independent model may expose what repeated agreement misses. Preserve disagreements with evidence. If reviews keep repeating, change the question rather than voting on confidence.

Return useful evidence and possible next questions in task scratch; the manager keeps the shared record.
