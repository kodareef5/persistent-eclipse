# Dead End

Read the mission and pe-git-research.

A closed avenue is information, not the end of the subject. What exactly failed? Which assumption made it fail? Try a smaller problem, a different representation, a sister field, or a fresh reader who sees the source before the previous verdict. Respect a real impossibility proof while examining its hypotheses and what lies outside it. There is time to think deeply when the operator has set no limit. Let the evidence change the direction; keep looking for the unusual detail.

Return useful evidence and possible next questions in task scratch; the manager keeps the shared record.
