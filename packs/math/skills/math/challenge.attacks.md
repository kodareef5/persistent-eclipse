### Counterexample and proof attacks · Challenge

| Attack | Press on |
| --- | --- |
| Vacuity | Are the hypotheses satisfiable? Does an empty type or empty set make the theorem automatic? |
| Quantifier reversal | What happens if the witness must be chosen before the adversarial parameter? |
| Dependency leak | Does a supposedly uniform constant secretly depend on the object or scale? |
| Degeneracy | Try zero objects, repeated roots, rank-deficient maps, disconnected spaces. |
| Endpoint | Inspect strict versus non-strict inequalities and excluded boundary parameters. |
| Scaling | Does either side transform at incompatible rates? |
| Dimension | Does the bound survive in dimension one, high dimension, or the limit? |
| Extremizer | Test equality cases and perturbations of known sharp examples. |
| Random model | Is the proposed behavior typical, exceptional, or contradicted with high probability? |
| Explicit construction | Build a structured, sparse, oscillatory, or adversarial object. |
| Small exhaustive cases | Does the first nontrivial finite instance already fail? (Try a small exact computation.) |
| Regularity | Where does the proof need continuity, completeness, measurability, or integrability? |
| Compactness | Can mass, norm, or witnesses escape to infinity? |
| Limit exchange | Is moving limit past sum, integral, supremum, or expectation justified? |
| Hidden cancellation | Are signs, absolute values, phases, or correlations discarded illegitimately? |
| Local-global leap | Do local solutions satisfy compatibility conditions for a global object? |
| Analogy / transfer | Does a toy model omit the very feature on which the theorem depends? |
| Circularity | Is a cited lemma equivalent to, stronger than, or derived from the claim? |
| False general lemma | Does the proof use a claim beyond the regime it was proved in? |
| Normalization drift | Are compared norms, measures, metrics, units, or conventions identical? |
| Equality / stability | Does the result claim uniqueness, strictness, or rigidity without ruling out near-extremizers? |
| Computation gap | Are floating-point output, finite search, and symbolic identities being confused with proof? |
| Formal gap | Did Lean check a theorem with `sorry`, unexpected axioms, or a materially altered statement? |
