### Mathematical moves · Explore

| Family | Move | Generating question |
| --- | --- | --- |
| Simplify | Normalize / rescale | What changes after fixing one natural size or constant? |
| Simplify | Equivalent reformulation | Is the same claim easier as an inequality, construction, invariant, or dual statement? |
| Simplify | Toy model | What survives in dimension one, a finite case, or a model space? |
| Simplify | Reduction | Which standard theorem would settle this if its hypotheses held? |
| Structural | Invariants / monovariants | What remains fixed, or can move in only one direction? |
| Structural | Symmetry / quotient | Can symmetry remove degrees of freedom without losing the extremal case? |
| Structural | Extremal / minimal example | What does a smallest counterexample or maximizer force? |
| Structural | Local-to-global | Which local compatibility condition would allow gluing? |
| Structural | Compactness | Can approximate or finite solutions yield a limit; what topology is needed? |
| Structural | Stability | If equality is nearly attained, must the object resemble an extremizer? |
| Discrete | Induction / descent | Which size, complexity, dimension, or scale decreases? |
| Discrete | Double counting | Can one quantity be counted in two ways? |
| Discrete | Generating function | Does a recurrence become an algebraic or analytic identity? |
| Discrete | Polynomial method | Can a carefully chosen polynomial encode forbidden configurations? |
| Analytic | Scaling / critical exponent | Which homogeneity would make the estimate possible or impossible? |
| Analytic | Approximation / density | Can a dense class be solved first, with a justified limit passage? |
| Analytic | Fourier / spectral transform | Does convolution, oscillation, or an operator simplify in a transformed basis? |
| Analytic | Energy / potential | Is there a quantity that decreases, concentrates, or controls error? |
| Probabilistic | Random construction | Would a random object usually satisfy the desired property? |
| Probabilistic | Moment / concentration | Which expectation, variance, tail, or entropy estimate controls exceptions? |
| Probabilistic | Coupling | Can two processes be compared on one probability space? |
| Optimization | Convexity / duality | Is there a primal-dual certificate, tangent bound, or variational principle? |
| Optimization | Perturbation | What do first-order changes and equality conditions reveal? |
| Advanced | Structure vs randomness | Can the object split into structured and pseudorandom parts? |
| Advanced | Tensor / power amplification | Does taking products strengthen a weak inequality or expose the optimal exponent? |
| Advanced | Transference | Can a result move between models without changing its meaning? |
| Advanced | Entropy / information | Can counting or dependence be recast as information bounds? |
