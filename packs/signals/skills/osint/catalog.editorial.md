# Editorial intelligence, audiences and web ecosystems

Source routes from the operator-supplied Round 2 fieldbook. These are documented
leads, not a claim that every API was tested. See [provenance](fieldbook.md) and
[catalog conventions](catalog.md); use the original documentation before collection.

| Source | Investigative opening | Limit |
| --- | --- | --- |
| [Media Cloud Search](https://www.mediacloud.org/media-cloud-search) | Compare how attention to a topic spreads across media source sets and geographies. | Syndication duplicates, source selection and indexing create large measurement biases. |
| [Google Trends API alpha](https://developers.google.com/search/apis/trends) | Research **consistently scaled** search-interest time series across requests (limited alpha access). | **Not generally public**; application required. UI series may use incomparable scaling. |
| [Google Search Console API](https://developers.google.com/webmaster-tools/v1/how-tos/search_analytics) | Analyze an operator-authorized site's queries, devices, countries, impressions and changes. | Only verified property access; sampling/aggregation/truncation; causality not established. |
| [Google Chrome UX Report / BigQuery](https://developer.chrome.com/docs/crux/bigquery) | Investigate real-user performance trends by origin and month as part of competitive technical context. | Aggregate selected Chrome experiences, not a direct traffic or user-count measure. |
| [Ahrefs API](https://docs.ahrefs.com/en/api/docs/introduction) | Inspect visibility, backlinks and content/topic gaps alongside the site's actual capabilities. | Third-party estimates differ; commercial API access. |
| [Semrush API](https://developer.semrush.com/api/v3/seo/overview/) | Compare overlapping search demand and competitive positions; identify unusual topic opportunities. | Estimated volumes, not true conversion intent. |
| [SparkToro](https://sparktoro.com/support/faq/what-sparktoro-covers) | Find newsletters, podcasts, sites and creators whose audiences overlap the operator's audience. | Observed digital footprints overrepresent visible/popular sources. |
| [Wappalyzer technology lookup](https://www.wappalyzer.com/docs/api/v2/lookup/) | Identify shifts in tech-stack footprints across tracked websites. | Inference and cached scans aren't verified installation histories. |
| [Common Crawl Index](https://index.commoncrawl.org/) | Search historical page presence, URL patterns and broader publication footprints. | Highly uneven sample; a missing crawl doesn't mean a page never existed. |
| [Techmeme](https://www.techmeme.com/about) | Study a functioning professional editorial *signal ranking and linking* system. | Editorial selection is not a ground-truth measure of importance. |
| [Data Is Plural archive](https://www.data-is-plural.com/archive/) | Find surprising public datasets that can seed original investigative beats. | Dataset existence doesn't equal quality or rights to republish. |

### Investigation seeds

Try **emerging technical discussion → audience intent → existing coverage gaps → original evidence → content opportunity**. A niche Reddit thread alone isn't a story; five independent communities asking the same unserved question may be.
