### Crossover prompts · Frontiers

| Pair of ideas | New question |
| --- | --- |
| Parser differential × agent tool arguments | Does the model's structured value mean something different to the execution tool? |
| Cache-key confusion × tenant search | Could a private search result be reused without its original principal filter? |
| Source/sink analysis × new framework | Which framework-specific APIs should be modeled as security-sensitive sinks? |
| Release diffs × vendor forks | Did a security fix preserve its invariant across bindings and backports? |
| SSRF / URL parsing × retrieval agent | Does the final fetch obey a host policy independent of LLM-generated URLs? |
| Localhost trust × desktop AI assistants | Is there a UI-only assumption in a service now exposed to browser-origin requests? |
| OAuth audience × MCP delegation | Do client, MCP server, and downstream API each enforce their own token audience? |
| Time-of-check × scheduled agent | Does a permission revoked today still authorize tomorrow's queued action? |
| Untrusted document × persistent memory | Can external material survive as future authority without provenance? |
| Archive parsing × AI file ingestion | Does an upload's secondary extraction/parsing escape its original file constraints? |
| Browser-origin restrictions × remote-control tools | Can a browser agent invoke a local capability the webpage itself lacks? |
| Failure retry × expensive inference | Can a minor malformed task repeatedly consume shared compute or quota? |
| Privileged host helper × sandbox | Which copy, logging, or networking operation bypasses the intended isolation? |
| Error oracle × search filters | Can returned errors, sizes, or timing reveal facts about inaccessible records? |
| Multilingual stack × canonicalization | Does a proxy, SDK, and database interpret identifier/path bytes the same way? |
| Human approval × dynamic tools | What happens if the user approved one tool schema but the implementation later changes? |
| AI-generated fix × semantic variant | Which related path remains vulnerable because only a payload signature was blocked? |
| “Safe” read-only tool × transitive action | Does reading a document trigger fetches, conversions, plugin hooks, or other side effects? |
