### Public side streets, archives, and specialist hangouts · Ecosystem

| Corner to read | Who / what shows up | Inspiration to bring back |
| --- | --- | --- |
| [Phrack issue archive](https://archives.phrack.org/issues/) | Decades of low-level exploit and system-internals writing. | What old boundary or trick disappeared from fashion but not from software? |
| [PoC or GTFO archive](https://pocorgtfo.reilly.io/) | Weird machines, bizarre file formats, reproducible demonstrations. | Can a “harmless” artifact have two valid meanings? |
| [Corkami docs](https://github.com/corkami/docs) | Byte-level oddities, executable formats, PDF tricks, packers. | Which assumption about a file header or layout is too simple? |
| [USENIX WOOT](https://www.usenix.org/conference/woot26) | Peer-reviewed offensive research and open proceedings. | Which technique is demonstrated in a controlled model but unexplored in an adjacent product? |
| [OffensiveCon archive](https://www.offensivecon.org/) | Advanced exploitation and reverse-engineering talks; see the Archive navigation. | What uncommon primitive, compiler behavior, or target class suggests a new seam? |
| [CCC talk archive](https://media.ccc.de/) | Hardware, protocols, privacy, retrocomputing, protocol research. | Which supposedly settled interface has surprising historical behavior? |
| [CTFtime writeups](https://ctftime.org/writeups) | Challenge authors and solvers publish clever constraint bypasses. | Which trick transfers to real code **only after** checking the missing assumptions? |
| [r/netsec](https://www.reddit.com/r/netsec/) | Curated disclosures and technical writeups with comments. | What did the community question about the claimed preconditions? |
| [r/ReverseEngineering](https://www.reddit.com/r/ReverseEngineering/) | Binary research, tool internals, firmware, reversing writeups. | Where does the shipped binary tell a different story than source? |
| [Lobsters / security](https://lobste.rs/t/security) | Practitioner-heavy technical links and threaded disagreement. | Which rebuttal or follow-up is more useful than the headline? |
| [oss-security](https://www.openwall.com/lists/oss-security/) | Original OSS disclosures, rebuttals, affected-version debates. | Was the public exploit description narrower than the root cause? |
| [SecLists archives](https://seclists.org/) | Full Disclosure, legacy Bugtraq, tool-development lists, RSS. | Which old patch/discussion exposes a still-relevant platform quirk? |
| [Linux kernel mailing-list archive](https://lore.kernel.org/lkml/) | Patch reviews, ABI contracts, hardening debates; access may vary. | Which safety rule exists only as an argument in a review thread? |
| [GitHub Issues and Discussions](https://github.com/features/issues) | Maintainer design decisions, platform-specific bug reports, proposed fixes. | What unfinished feature or closed “won't fix” changes the threat model? |
| [ecosyste.ms issues](https://issues.ecosyste.ms/) | Cross-forge issue and PR metadata. | Which symptom appears independently in two related projects? |
| [OSS-Fuzz project issues](https://github.com/google/oss-fuzz/issues) | Public fuzz harness and coverage problems, project setup discussions. | Which complex parser mode has coverage in name only? |
| [Google Project Zero RCA corpus](https://googleprojectzero.github.io/0days-in-the-wild/) | Root causes, timeline, variant context for exploited bugs. | What earlier patch made the bug class look closed? |
| [ZDI research and advisories](https://www.zerodayinitiative.com/) | Vendor-independent disclosures, contest research, patch analysis. | Which arbitrary file or object primitive becomes dangerous under a privileged service? |
| [GitHub Security Lab archive](https://securitylab.github.com/research-archive/) | Source-backed multi-project investigations, CodeQL writeups. | Does a framework-specific model reveal variants no generic check can see? |
| [HackerOne public Hacktivity](https://hackerone.com/hacktivity) | Disclosed bounty reports with preconditions and triage context. | What crossed-principal consequence separated a real issue from a self-only bug? |
| [Pentester Land writeups directory](https://pentester.land/) | Handpicked bug bounty and coordinated-disclosure articles. | Which one unusual application behavior defeated the usual recipe? |
| [PortSwigger Research](https://portswigger.net/research) | New protocol, parser, browser, cache, and data-model techniques. | Which research lineage has more variants than its best-known payload? |
| [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) | Broad public catalog of edge cases and test concepts. | What *semantic* behavior is behind a bypass, not just what string worked? |
| [OpenSSF malicious packages](https://github.com/ossf/malicious-packages) | Public package incident datasets and taxonomy debates. | What is the actual publisher, installer, or manifest trust boundary? |
| [OpenSSF package analysis](https://github.com/ossf/package-analysis) | Public package behavior-analysis work and case studies. | Did a package's behavior change in a way the source diff hides? |

These are public research communities and archives—not invitations to access private channels, stolen data, or systems outside the mission. Historic writeups and contest puzzles are **idea generators**; modern reachability must be established in actual code.
