### Historical hacks worth stealing ideas from · Frontiers

| Published case / original source | The surprising mechanism | L3 · Modern question to borrow |
| --- | --- | --- |
| [Ken Thompson's Trusting Trust, revisited](https://research.swtch.com/nih) | A compiler binary can carry behavior absent from apparently clean source. | What trusted build/tool component can change the meaning of reviewed inputs? |
| [xz/liblzma backdoor disclosure, 2024](https://www.openwall.com/lists/oss-security/2024/03/29/4) | The release tarball contained a build-stage change absent from the ordinary Git source view. | Are provenance, tests, release artifacts, and executed objects the same thing? |
| [Dependency confusion, 2021](https://medium.com/@alex.birsan/dependency-confusion-how-i-hacked-into-apple-microsoft-and-dozens-of-other-companies-4a5d60fec610) | Package resolution crossed an internal/public naming boundary. | Which name or identifier is considered private without enforcing a unique authority? |
| [HTTP request smuggling research lineage](https://portswigger.net/research/request-smuggling) | Front and back servers disagree about message framing. | Which two components still disagree about where one operation ends? |
| [HTTP/1.1 must die, 2025](https://portswigger.net/research/http1-must-die) | Compatibility workarounds leave deeper framing ambiguity alive. | Does a middleware “mitigation” remove the invariant violation or only familiar examples? |
| [Orange Tsai: path normalization research, 2018](https://blog.orange.tw/posts/2018-08-how-i-chained-4-bugs-features-into-rce-on-amazon/) | Several parsers attach different meanings to the same path. | Is approval performed over the same final representation that execution uses? |
| [Practical web cache poisoning, 2018](https://portswigger.net/research/practical-web-cache-poisoning) | An unkeyed input affects cached output consumed by a different audience. | Which per-user inputs are missing from a shared cache or AI response key? |
| [Zip Slip disclosure, 2018](https://snyk.io/blog/zip-slip-vulnerability/) | Archive entry names can affect filesystem locations after unpacking. | Do installers, dataset imports, and artifact restorers apply the same destination rule? |
| [Corkami's Mitra polyglots](https://github.com/corkami/mitra) | One byte sequence can be valid under more than one file format. | Can a scanner approve one interpretation while a later component acts on another? |
| [Heartbleed, 2014](https://heartbleed.com/) | A declared length was trusted more than the bytes actually present. | Which length, count, or pointer was supplied by a different trust domain? |
| [Log4j security advisories](https://logging.apache.org/security.html) | Diagnostic logging can unexpectedly invoke interpreter-like behavior. | What other “observation only” subsystem can evaluate, resolve, or fetch? |
| [Shellshock (CVE-2014-6271)](https://nvd.nist.gov/vuln/detail/CVE-2014-6271) | Environment data could be parsed as executable shell content in affected Bash versions. | Which boundary reclassifies passive metadata into a command or program? |
| [Cloudflare parser memory leak report, 2017](https://blog.cloudflare.com/incident-report-on-memory-leak-caused-by-cloudflare-parser-bug/) | A parsing edge leaked unrelated memory into responses. | Which high-performance wrapper processes many tenants with shared native state? |
| [Project Zero Rowhammer research, 2015](https://projectzero.google/2015/03/exploiting-dram-rowhammer-bug-to-gain.html) | Hardware disturbance crossed an apparent memory isolation boundary. | Is an isolation guarantee dependent on lower-layer behavior it doesn't control? |
| [Spectre and Meltdown, 2018](https://spectreattack.com/) | Microarchitectural side effects leak data despite architectural access rules. | What timing, size, or resource side channel survives an otherwise correct permission check? |
| [DNS rebinding / browser-origin advisories](https://www.kb.cert.org/vuls/id/652514) | Network destination and browser-origin trust can diverge over time. | Which localhost bridge assumes browser requests cannot originate from an attacker? |
| [GitHub Security Lab: The weakest link](https://securitylab.github.com/research/the-weakest-link/) | A shared library's design choice undermined multiple consumers. | Which trusted dependency has a security footgun that several wrappers inherited? |
| [ZDI: turning file deletes into stronger primitives](https://www.zerodayinitiative.com/blog/2022/3/16/abusing-arbitrary-file-deletes-to-escalate-privilege-and-other-great-tricks) | A weak-looking filesystem capability becomes more powerful when combined with system behavior. | What unexpected *second component* acts on the state left by a weak primitive? |
| [Google structure-aware fuzzing](https://github.com/google/fuzzing/blob/master/docs/structure-aware-fuzzing.md) | Generic fuzzing misses states that require valid structured input or action sequences. | Which input path is “fuzzed” but never reaches its difficult states? |
| [PortSwigger 2025 technique winners](https://portswigger.net/research/top-10-web-hacking-techniques-of-2025) | Unicode, ORM, XS-Leaks, caches, and error oracles produce fresh results from old ingredients. | Which commonplace operation becomes informative or dangerous only when combined with another? |

The point is **mechanism transfer**, not replaying an old payload or implying modern targets share the original bug. Years name the published research or disclosure, not affected product versions.
