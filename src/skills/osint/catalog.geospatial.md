# Geospatial, environment, humanitarian and infrastructure

Source routes from the operator-supplied Round 2 fieldbook. These are documented
leads, not a claim that every API was tested. See [provenance](fieldbook.md) and
[catalog conventions](catalog.md); use the original documentation before collection.

| Source | Investigative opening | Limit |
| --- | --- | --- |
| [Copernicus Data Space](https://dataspace.copernicus.eu/) | Time series of public Earth observations around industrial or humanitarian activity. | Clouds, resolution, sensing modality, irregular revisit. |
| [NASA FIRMS](https://firms.modaps.eosdis.nasa.gov/) | Rapid screening for heat anomalies and fires; compare with news reports. | Not reliable confirmation of a named event or actor by itself. |
| [Global Fishing Watch API](https://globalfishingwatch.org/our-apis/documentation/) | Analyze maritime movement and apparent fishing activity. | Documented noncommercial API terms and AIS limitations; do not claim illicit activity solely from observed gaps. |
| [OpenStreetMap Overpass](https://wiki.openstreetmap.org/wiki/Overpass_API) | Look for changing business, road, industrial, and infrastructure map objects. | Volunteer coverage differs dramatically; tags aren't verified ground truth. |
| [OpenAQ](https://openaq.org/) | Trace public air-quality sensor history and anomalous environmental patterns. | Sensor placement, maintenance and calibration bias. |
| [USGS Earthquake APIs](https://earthquake.usgs.gov/fdsnws/event/1/) | Watch seismic events and event revisions; contextualize infrastructure disruptions. | Event location uncertainty and reported effects vary. |
