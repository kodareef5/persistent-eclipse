# Catalogs and field guides

Other people's lists, for when the lab needs a kind of source it doesn't have yet.
Read them for ideas and check each source before relying on it. Use the shared
[catalog conventions](catalog.md).

| Catalog | URL | What it is |
| --- | --- | --- |
| Bellingcat Online Investigation Toolkit | `https://bellingcat.gitbook.io/toolkit` | Practitioner-maintained tools by category: companies, maps, archives, social media, verification |
| OSINT Framework | `https://osintframework.com/` | A tree of resources organized by what you start from |
| awesome-osint | `https://github.com/jivoi/awesome-osint` | A very large categorized list; uneven, and many entries are about people, which this lab doesn't investigate |
| public-apis | `https://github.com/public-apis/public-apis` | Free APIs by subject, useful for finding a feed in a new field |
| Data Is Plural | `https://www.data-is-plural.com/archive/` | A weekly newsletter archive of interesting public datasets |
| GIJN resources | `https://gijn.org/resource/` | Investigative journalism guides, including company and records research. Baseline browser challenge; use a permitted access route (see UPDATES) |
| HN API documentation | `https://github.com/HackerNews/API` | Item and list semantics for the collector |
| Data.gov | `https://catalog.data.gov/dataset/` | Public dataset discovery; inspect the publishing agency’s collection and release process |
| Google Dataset Search | `https://datasetsearch.research.google.com/` | Find datasets across domains; metadata does not establish quality or usable access |

[Expert feeds and reading rooms](fieldbook.feeds.md) cover sources that teach
investigative craft as well as sources that report events.
