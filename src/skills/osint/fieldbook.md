# Signals professional fieldbook

Open the part that helps the investigation. These are research possibilities and
examples of craft, not a new mission, a checklist to finish, or a reason to build
more infrastructure. Try an unexpected route, keep what it teaches, and return to
the operator's question. PE's existing scope, resource permissions, fleet, records,
and delivery expectations still govern the work.

| Need | Read |
| --- | --- |
| Capture a source, reconcile messy entities, query a corpus, study a professional tool | [Toolbench](fieldbook.tools.md) |
| Find an unusual investigative move or test a favorite explanation | [21 investigative plays](fieldbook.plays.md) |
| See how real researchers make evidence inspectable | [Published investigations and research products](fieldbook.examples.md) |
| Find specialist interpretation, methods, or early official records | [Expert feeds and reading rooms](fieldbook.feeds.md) |
| Find a concrete source by subject | [Source catalog](catalog.md) |
| Develop a desk or improve its deliverable | pe-hunt's `notes/desks.md`, `notes/desks.specialist.md`, and `notes/output.specimens.md` |

Useful starting questions: who does unusually well under the same constraints?
What has to happen between an announcement and its effect? What would the sensor
miss? Which apparently independent claims share one source? What would change if
a dismissed idea were right? Pick a thread; don't run every play against every lead.

## How far these entries were checked

Most entries are research leads gathered from public documentation and published
work, not independently revalidated capabilities. Paid products were not trialed,
data APIs were not exercised, and published investigations were not reproduced.
Access labels are starting knowledge; inspect current official documentation when
you use a route. The key sources below were checked on 2026-10-31.

| Basis | Source checked | What that establishes here |
| --- | --- | --- |
| Documentation checked | [Google Trends alpha](https://developers.google.com/search/apis/trends) | Limited approval-based access and consistent scaling across API requests; not a generally open API |
| Documentation checked | [Federal Register public inspection](https://www.archives.gov/federal-register/public-inspection) | Documents are available before formal publication; this does not establish when a rule takes effect |
| Documentation checked | [PitchBook research process](https://pitchbook.com/help/pitchbooks-research-process) | Its described discovery, scope, verification, quality review, and ongoing profile-update process |
| Documentation checked | [OpenAlex filters](https://help.openalex.org/api/filtering/#sync-filters-paid-plans) | Created/updated record sync filters require paid plans; publication-date filtering is a different operation |
| Documentation checked | [GFW methodology](https://globalfishingwatch.org/dataset-and-code-fishing-activity/) and [API documentation](https://globalfishingwatch.org/our-apis/documentation/) | Apparent activity is modeled, receiver coverage changes, and documented API access is noncommercial |
| Documentation checked | [ForecastBench](https://forecastingresearch.org/research/forecastbench) | Its stated use of new future-event questions and later evaluation; not proof of a PE lab's performance |
| Documentation checked | [SemiAnalysis Core Research](https://semianalysis.com/core-research/) | Its described combination of technical, supply-chain, and company analysis; no subscriber model evaluation |
| Documentation checked | [The Information Pro](https://www.theinformation.com/pro) | Reporting plus proprietary research databases; subscriber tools not evaluated |
| Published case checked | [Bellingcat's single-image reconstruction](https://www.bellingcat.com/resources/case-studies/2014/07/18/identifying-the-location-of-the-mh17-linked-missile-launcher-from-one-photograph/) | The published trail through visible lettering, an address in a court document, maps, and matching video landmarks |
| Published case checked | [ICIJ Implant Files](https://www.icij.org/investigations/implant-files/about-the-implant-files-investigation/) | Its reported collaboration and device-record analysis; the article does not make adverse-event reports causal incidence estimates |
| Published case checked | [OCCRP Dubai Unlocked](https://www.occrp.org/en/project/dubai-unlocked/what-is-dubai-unlocked-everything-you-need-to-know) | The project's account of its source material and verification; a lesson in corroboration, not permission to acquire leaked records |
| Published method checked | [GIJN positive-deviant investigations](https://gijn.org/?p=3125108) | A direct account of comparing unusually successful peers under similar constraints |

Keep subsequent access checks and corrections under the existing
[catalog conventions](catalog.md). No per-entry review ritual is required. A
provider's product page establishes what it advertises, not that its conclusions
are reliable or that its data is available to this lab.
