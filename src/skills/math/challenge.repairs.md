### Salvage questions · Challenge

| If the route fails because… | Ask instead… |
| --- | --- |
| A counterexample exists | What extra assumption excludes it without making the theorem empty? |
| An estimate is too strong | Is the right answer a weaker exponent, constant, norm, or mode of convergence? |
| A boundary case fails | Can the theorem be split at a sharp threshold? |
| A uniform theorem fails | Does a parameter-dependent or local version remain useful? |
| The general case resists | Can a structured, low-dimensional, smooth, finite, or generic subclass be proved? |
| The key lemma is false | Is a nearby true lemma enough; can the proof route be changed? |
| A limit step fails | Is compactness, domination, tightness, or a different topology available? |
| A toy model works but transfer fails | Which property of the full setting blocks transfer? |
| A formal proof fails | Is this a tactic problem, missing library lemma, true mathematical obstruction, or statement mismatch? |
| Computation only supports a pattern | Which smaller theorem would explain the pattern without extrapolating? |
| A stronger theorem is already known | Can the new contribution be a simpler proof, explicit construction, new regime, or formalization? |
